# AI Coding Workflow

This repository contains a sanitized version of the instructions I use when working with AI coding agents.

The rules focus on:

- scope control;
- code review and testing;
- honest reporting of validation results;
- security and privacy;
- pull-request workflows; and
- human approval for merges and deployments.

The guidance is intentionally project-neutral and contains no proprietary code, customer data, internal URLs, or company-specific information.

See [AGENTS.md](AGENTS.md) for the complete rules.
